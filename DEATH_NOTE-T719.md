# DEATH NOTE — TRACK T719: INVALID PRESENT FENCE

## VERDICT: FAIL

## WHAT T719 SET OUT TO DO

BREAK THE "INVALID PRESENT FENCE" WALL: 2,241
`TRACKPENDINGFRAME: INVALID PRESENT FENCE` ERRORS IN THE T718
FLIGHT-01 UART, WITH QUEUEBUFFER 0 AND PRESENT 0. DISASSEMBLE
TRACKPENDINGFRAME AND THE PRODUCER FENCE ORIGIN FRAMEWORK-FIRST,
DISCRIMINATE DROP-VS-SKIP, APPLY THE SMALLEST FIX.

## WHAT T719 PROVED (STEP 2, FROM THE GUEST'S OWN BINARIES)

- THE CHECK: SURFACEFLINGER `0X204054-0X204060` LOGS THE ERROR WHEN
  `FENCETIME::GETCACHEDSIGNALTIME()` RETURNS -1. CACHED SIGNAL TIME
  IS -1 EXACTLY WHEN THE FENCE FD IS -1 (LIBUI CTOR, FENCE+12).
- THE ORIGIN: `COMPOSERCLIENTIMPL::PRESENT()` (`0X5BF1C`) TAIL-CALLS
  `SETPRESENTFENCE(-1)` — `MOV W1, #-1` HARDCODED AT `0X5BFF4` — ON
  ALL PATHS, AFTER WRITING FB0.
- NO FENCE SOURCE EXISTS: KERNEL HAS NO `CONFIG_SW_SYNC`;
  `SW_SYNC_*` IS STATICALLY LINKED WITH ZERO CALL SITES (DEAD CODE).
- SKIP, NOT DROP: THE SCHEDULER ERROR PATH BRANCHES BACK INTO THE
  LOOP (`B 0X204078`); THE COMPOSER WRITES FB0 BEFORE RETURNING -1.
- QUEUEBUFFER/PRESENTDISPLAY LITERALS ARE UNOBSERVABLE ON SUCCESS
  PATHS: LIBGUI HAS NO QUEUEBUFFER LOG STRINGS; SURFACEFLINGER HAS
  ONLY AN ERROR-ONLY QUEUEBUFFER STRING.

## WHAT T719 BUILT AND FLEW

A 4-BYTE SCAFFOLD PATCH TO THE GUEST SURFACEFLINGER BINARY AT
`0X204060`: `B.EQ LOG-BLOCK` → `B LOOP-CONTINUE`. IT SILENCES ONLY
THE LOG LINE; THE UNDERLYING -1 RETIRE FENCE REMAINS. PATCHED
SURFACEFLINGER SHA `FADEE423…`; NEW SYSTEM.IMG SHA `AC15A68A…`
(2,059,816,960 B; INODE 556 REUSED; E2FSCK CLEAN; 9 NEIGHBOURS
BYTE-IDENTICAL; INSTALLD.RC PRESERVED; BASE UNTOUCHED). T718 STACK
UNCHANGED (VENDOR `BAC3CDC1`, CPIO `1150C841`, DTB `D298F5AD`,
IMAGE `53D9563E`, SHIM `3DAA5A49`).

## WHY FAIL

THE LITERAL PASS CRITERIA (QUEUEBUFFER > 0, FIRST PRESENT DISPATCH)
ARE UNACHIEVED, AND QUEUEBUFFER IS PROVEN UNOBSERVABLE ON SUCCESS
PATHS. THE FENCE WALL IS SILENCED BY SCAFFOLD ONLY: THE -1 RETIRE
FENCE REMAINS, AND NO FENCE SOURCE EXISTS IN THE GUEST.

## THE REAL FIX (NAMED, MULTI-LANE PROGRAM)

KERNEL FENCE SOURCE (`CONFIG_SW_SYNC` KERNEL REBUILD) + SW_SYNC
RETIRE FENCE IN THE COMPOSER BACKEND + EGL NATIVE-FENCE SUPPORT.
THE SCAFFOLD MUST BE REPLACED BY IT AND NEVER MISTAKEN FOR THE FIX.

## REFLECTION

THE DISASSEMBLY IDENTIFIED THE MISSING FENCE SOURCE BEFORE THE
FLIGHT; THE SCAFFOLD-VS-FIX DISTINCTION WAS RECORDED BEFORE FLYING.
THE SUCCESSOR MUST START FROM THE KERNEL CONFIG (CONFIG_SW_SYNC
REBUILD) AND REVERT THE SCAFFOLD WHEN THE REAL FIX LANDS. THE
LITERAL QUEUEBUFFER CRITERION MUST BE REPLACED BY AN OBSERVABLE
PROXY IN FUTURE BRIEFS.
