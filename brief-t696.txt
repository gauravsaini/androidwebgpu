# Track T696 — Route B rebuild: non-LTO + linker-script globs (Mac agyx, build on box)

## Mission

Successor to driver-certified T695 honest FAIL. Route A is DEAD on a
SECOND, distinct Clang 21 defect (T695, driver-verified 2026-11-08):
ThinLTO section-suffixing (`.initcall*.init..<suffix>`) orphaned all
initcall sections into `.data` — `__initcall_start ==
__initcall_end == 0xffffff8009293c48` (empty initcall table, 0
initcalls executed; driver re-count via box llvm-readelf: 713 suffixed
initcall sections, 0 non-suffixed), zero drivers initialized, guest
panic at 0.113 s ("Attempted to kill init!"). The T688 defect
(`.text.unlikely` orphaned into the init range, free_initmem zeroing,

gate PASSES on the Route A Image (all five key functions below

worktree, 10,923 B): the deterministic fix — ONE linker-script edit
teaching the 4.19 linker script the clang suffix globs — on the
NON-LTO T686 config (`CONFIG_LTO_NONE=y`, clang 21). Non-LTO removes
the ThinLTO suffixing that caused defect 2; the linker-script globs
remove the orphaning that caused defect 1. Both defects are addressed
by construction; the gates below prove it before any flight.

route was proven by T695 itself (launched 08:47 AEDT 2026-11-08, agent

Background (T688 root cause + T695 second defect, both
driver-verified):
- Defect 1 (T686/T688): Linux 4.19 `TEXT_TEXT` matches
  `.text.unlikely` and `.text.hot` exactly. Clang 12+ emits
  `.text.unlikely.` / `.text.hot.` (trailing dot), so LLD
  orphan-places the cold sections into the freeable init range;
  free_initmem zeroes them; `bl printk` executes `udf #0x0`; nested
  die() self-deadlocks on die_lock. Canonical kernel (clang 11.0.1)
  places printk 0xffffff8008216980 below _etext and boots.
- Defect 2 (T695): Clang 21 ThinLTO suffixes `.initcall*.init`
  sections (`.initcall6.init.<suffix>` etc.); LLD orphan-places all
  713 of them into `.data`; `__initcall_start == __initcall_end`
  (empty table); 0 initcalls run; kernel_init_freeable falls back to
  prepare_namespace → mount_block_root → printk_all_partitions → Oops
  (DABT reading VA 0x100) → 'Kernel panic - not syncing: Attempted to
  kill init! exitcode=0x0000000b' at guest 0.113 s. Freeing unused
  kernel memory + init first stage NOT reached; fb0 never registered.
- Route B (this lane): keep the T686 config unchanged
  (`CONFIG_LTO_NONE=y`, clang 21, DEVMEM/FB/FB_SIMPLE/
  DRM_FBDEV_EMULATION=y) and apply the ONE linker-script edit below.
  Non-LTO means no ThinLTO suffixing (defect 2 gone by construction);
  the globs mean the cold sections land in .text (defect 1 gone by
  construction).

### Step 2 — Apply Route B and rebuild (box, over SSH)

Exactly ONE source edit, in /home/muse/t686-kernel/src/
`include/asm-generic/vmlinux.lds.h`, in `TEXT_TEXT` (per
rebuild-recipe.md Route B):

```
-		*(.text.hot TEXT_MAIN .text.fixup .text.unlikely)	\
-		*(.text..refcount)					\
-		*(.ref.text)						\
+		*(.text.hot .text.hot.* TEXT_MAIN .text.fixup)		\
+		*(.text.unlikely .text.unlikely.*)			\
+		*(.text.unknown .text.unknown.*)			\
+		*(.text..refcount)					\
+		*(.ref.text .ref.text.*)				\
```

Why each pattern: `.text.unlikely.*` matches clang's
`.text.unlikely.` and `.text.unlikely.<function>` (the actual T686
orphan); `.text.hot.*` matches `.text.hot.` (same LLVM change, hot
half); `.text.unknown.*` covers clang's unknown-profile bucket;
`.ref.text.*` future-proofs `__ref` against suffixing. The old exact
names stay, so older compilers keep working. Do NOT edit the arm64
`vmlinux.lds.S`; `TEXT_TEXT` is the shared macro it expands. Record
the exact `git diff` of this edit in the findings (it must show ONLY
this file, ONLY these lines).

Build with the exact T686 command (from the box, in
/home/muse/t686-kernel/src, log to
/home/muse/t696-routeb-rebuild/build.log, run DETACHED with
setsid+nohup so an agent death cannot kill the build, then poll the
log — do not block the agent session on the build):

```
make -j5 ARCH=arm64 \
  CROSS_COMPILE=/home/muse/t686-kernel/toolchain-bin/aarch64-linux-gnu- \
  CLANG_TRIPLE=aarch64-linux-gnu- \
  CC=clang LD=ld.lld AR=llvm-ar NM=llvm-nm \
  OBJCOPY=llvm-objcopy OBJDUMP=llvm-objdump STRIP=llvm-strip \
  HOSTCC=gcc HOSTCXX=g++ \
  KCFLAGS="-fno-builtin-sprintf" \
  Image
```

`KCFLAGS="-fno-builtin-sprintf"` is mandatory: clang 21 rewrites
`sprintf(p,"%s",...)` in `tty_io.c` to `stpcpy`, which 4.19 does not
provide. Do not remove it. The NDK clang/LLD binaries come from
/home/muse/t681-link/toolchain/android-ndk-r29 — put its
`toolchains/llvm/prebuilt/linux-x86_64/bin` first on PATH for the build
(the T686 build-clang.sh in /home/muse/t686-kernel/ shows the exact
PATH setup; read it and follow it, do not improvise).

### Step 3 — Pre-boot gates (mandatory, before ANY flight)

Run BOTH gates on the box via SSH (NDK llvm-nm / llvm-readelf on
/home/muse/t686-kernel/src/vmlinux). Record every address verbatim.

Gate 3a — symbol gate (T688 defect must be gone):

```
llvm-nm vmlinux | grep -E ' (printk|__die|panic|dump_stack|show_regs|_etext|__init_begin|__init_end|free_initmem)$'
```

Required: every one of printk, __die, panic, dump_stack, show_regs
has an address STRICTLY below _etext (and therefore below
__init_begin). Reference values: Route A (PASS) printk
0xffffff800811a4c4, __die 0xffffff8008096bbc, panic
0xffffff80080b7770, dump_stack 0xffffff8008b41a64, show_regs
0xffffff800808ec28, _etext 0xffffff8008b70000; T686 (FAIL) had all
five at 0xffffff800923xxxx inside init; canonical printk
0xffffff8008216980 below _etext.

Gate 3b — initcall-table gate (T695 defect must be gone; NEW, this
lane's decisive gate):

```
llvm-nm vmlinux | grep -E ' (__initcall_start|__initcall_end)$'
llvm-readelf -S vmlinux | grep -c '\.initcall.*\.init\.'
llvm-readelf -S vmlinux | grep '\.initcall' | head -20
```

Required: `__initcall_start < __initcall_end` with a POPULATED table
(T686 contrast: start 0xffffff800924ab48, end 0xffffff800924b65c,
2,836 B populated; Route A FAIL: start == end ==
0xffffff8009293c48, empty). Required: the count of suffixed
`.initcall*.init.<suffix>` sections orphaned into `.data` is ZERO
(Route A had 713). A table of a few hundred bytes or more with zero
orphaned suffixed sections = PASS. An empty table (start == end) or
any orphaned suffixed initcall section = FAIL.
